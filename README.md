# GymTracker

Android-first, offline-first strength training log focused on transparent progressive overload and unlimited history.

The canonical product and engineering handoff is [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md).

## Current stage
Repository initialization. The Android bootstrap, progression engine, tests, CI, and persistence plan are being introduced through pull requests.

## Core promise
No subscription is required for the core product. Training history is designed to stay local and unlimited, with explicit export/import.
